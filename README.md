# Jaktlaget 1.2.1

Denna version innehåller jaktlagsnamn, aktivt jaktår, historik och rapportering.

## Nytt i 1.2.1
- Jaktlaget kan namnges under Inställningar.
- Namnet visas i sidhuvud, historik och rapporter.
- Aktivt jaktår kan avslutas. Nästa jaktår skapas och börjar från noll.
- Det avslutade jaktårets registreringar och fördelningssnapshot behålls.
- Statistik innehåller medlemskort och fördelningstabell.
- Årsrapport kan exporteras som semikolonseparerad CSV för Excel.
- Årsrapport kan öppnas som utskriftsvänlig vy och sparas som PDF via webbläsarens utskriftsdialog.
- Djurslagsrapport visar vuxen, ungdjur och vuxenekvivalenter.

## Publicering
Ladda upp alla filer till repositoryts rot och publicera med GitHub Pages.

## Lagring
All data lagras lokalt i aktuell webbläsare. Exportera regelbundet JSON-säkerhetskopia. CSV- och PDF-rapporter är avsedda för delning och arkivering.
